# Zoosy 应用实现功能清单

版本：v1.4.1
日期：2026-06-20
技术栈：Flutter (Dart) · Material 3 · 本地优先架构

---

## 一、核心功能

### 1. 思考记录（思考卡 CRUD）
- **新建思考卡**：填写标题、内容、标签、图片（最多9张），保存后自动生成时间戳
- **编辑思考卡**：修改已有记录的所有字段
- **删除思考卡**：二次确认弹窗防止误删
- **收藏/取消收藏**：星标标记重要思考
- **保存成功动画**：60粒子撒花庆祝动画 + 励志语句展示

### 2. 首页日历视图（思考足迹）
- **周历组件**：左右滑动切换周，支持无限滚动（PageView ±10000页）
- **日期选择**：点击日历日期筛选当日思考，内容区同步联动
- **双击月份**：快速回到今天
- **内容区左右滑动**：按天浏览思考记录，日历自动同步
- **有记录标记**：日历日期下方圆点提示当天有记录
- **空状态提示**：区分今天/过去/未来三种空状态文案

### 3. 全部思考列表
- **按日期分组**：时间倒序展示所有思考卡
- **日期分组标题**：每组显示日期和记录数量
- **卡片预览**：标题、时间、内容摘要（3行）、标签

### 4. 思考详情页
- **完整内容展示**：标题、日期时间、标签、正文、图片
- **AI 摘要展示**：毛玻璃卡片风格，显示 AI 生成的反思总结
- **编辑/删除操作**：底部固定操作栏
- **收藏切换**：顶栏星标按钮
- **分享功能**：
  - 文字分享：纯文本格式
  - 图片分享：渲染为精美卡片图片（含 Logo、标题、时间、标签、正文、图片）
- **图片全屏浏览**：小红书风格图片浏览器
  - 左右滑动切换、双击缩放、捏合缩放/旋转
  - 沉浸模式（隐藏系统栏）
  - 顶栏（返回 + 页码）、底栏（标题 + 标签）毛玻璃效果

### 5. 搜索功能
- **关键词搜索**：标题和内容全文匹配
- **热门标签**：以 FilterChip 展示自定义标签，点击即筛选
- **搜索历史**：最多保存10条，支持清空
- **组合过滤**：关键词 + 标签联合筛选

### 6. 收藏夹
- **收藏列表**：仅展示标记星标的思考卡
- **空状态提示**：无收藏时展示占位图

## 二、统计与数据可视化

### 7. 统计趋势页
- **时间维度切换**：日/周/月三种视图，分段选择器
- **折线图**（默认）：平滑曲线 + 渐变填充 + 数据点，横向滚动，自动定位到今天
- **柱状图**：按时间维度展示记录数量
- **环形图**：标签分布占比可视化
- **图表切换**：右上角菜单切换折线/柱状/环形
- **图表分享**：导出为 PNG 图片分享
- **今日/本周/本月统计卡片**：实时显示当前周期记录数

### 8. 数据洞察
- **总计卡片**：总记录数 + 周环比变化百分比（↑↓箭头）
- **连续打卡天数**：火焰图标 + 当前连续天数
- **最长连续记录**：奖牌图标 + 历史最佳纪录
- **每周洞察卡**：自动分析本周最活跃标签及增长情况
- **标签分布列表**：各标签记录数量 + 百分比，点击进入标签筛选页

## 三、AI 智能功能

### 9. AI 摘要生成
- **8个 LLM 提供商**：OpenAI、DeepSeek、Moonshot、豆包、Gemini、Claude/Sonnet、Kimi、通义千问
- **自动摘要**：保存思考卡时自动生成 ≤50字中文反思总结
- **API 配置**：设置页可配置 API Key、API URL、模型选择
- **API Key 验证**：一键检测 Key 有效性并反馈结果
- **开关控制**：可全局启用/禁用 AI 功能

### 10. 语音输入
- **语音转文字**：使用 speech_to_text 实现中文听写
- **VIP 限制**：免费用户每月3次，VIP/管理员无限制
- **麦克风权限管理**：自动请求权限，拒绝时提示

## 四、提醒与通知

### 11. 每日定时提醒
- **本地通知**：基于 flutter_local_notifications 的每日定时推送
- **自定义标题和内容**：可编辑通知标题（≤16字）和内容（≤30字）
- **测试通知**：一键发送测试通知验证配置

### 12. 屏幕使用时长提醒
- **后台监控**：每5分钟检测设备每日使用时长
- **双阈值提醒**：5小时和11小时各触发一次通知
- **静默时段**：00:00–05:30 不打扰
- **每日重置**：午夜后重置通知标志

### 13. 硬件快捷键触发
- **音量键/电源键组合**：通过 MethodChannel 监听硬件按键快速打开新建思考页
- **开关控制**：可在设置中启用/禁用

## 五、桌面小组件

### 14. Android 桌面小组件
- **3种小组件样式**：
  - 统计卡片样式：显示总记录数、今日记录数、连续天数
  - 快速记录样式：一键新建思考
  - 最近思考样式：展示最近5条思考预览
- **数据同步**：通过 HomeWidget + MethodChannel 双通道推送数据
- **主题色跟随**：小组件颜色跟随应用主题色变化
- **自定义标签**：可自定义小组件显示的标签文案
- **Logo 自动切换**：根据主题色自动匹配对应 Logo
- **使用引导**：3步图文教程指导添加小组件

## 六、用户系统

### 15. 注册与登录
- **邮箱注册**：昵称 + 邮箱 + 图形验证码 + 邮箱验证码 + 密码
- **邮箱登录**：邮箱 + 密码，支持记住密码
- **游客模式**：跳过登录直接使用（功能受限）
- **图形验证码**：自绘4位随机字符 + 干扰线/噪点 + 旋转变色
- **邮箱验证码**：60秒倒计时，QQ邮箱 SMTP 发送 HTML 样式邮件
- **用户协议**：注册时强制勾选，含完整的用户协议和隐私政策（各8章节）

### 16. 账号安全
- **修改密码**：旧密码验证 + 新密码确认
- **重置密码**：邮箱 + 验证码双因素身份验证
- **修改邮箱**：新邮箱验证码验证
- **手机号绑定**：预留入口（即将推出）
- **设备管理**：查看当前设备（绿色标识）和其他登录设备，支持远程删除

### 17. 个人资料
- **头像设置**：支持相册/相机拍照，本地存储
- **昵称、邮箱、性别**（男/女/保密）
- **生日选择**：日期选择器
- **职业、个性签名、个人简介**
- **编辑入口**：头像点击直接进入编辑页

## 七、主题与外观

### 18. 主题色
- **8种预设主题色**：思考紫、心动粉、极光绿、深海蓝、日落橙、樱花粉、暗夜金、极简灰
- **实时预览**：选择后展示模拟 App 界面效果
- **应用图标切换**：跟随主题色自动切换 Android 应用图标（MIUI 适配）

### 19. 深色模式
- **三种模式**：跟随系统 / 浅色 / 深色
- **完整适配**：所有页面深色模式适配（背景、卡片、文字、边框等）

### 20. 多语言支持
- **9种语言**：简体中文、繁体中文、英语、德语、法语、日语、韩语、俄语、泰语
- **系统语言跟随**：可选择跟随系统或手动指定
- **200+ 翻译键值**：覆盖所有 UI 文本

## 八、数据管理

### 21. 本地数据持久化
- **SharedPreferences 存储**：所有思考卡 JSON 序列化存储在本地
- **安全偏好设置**：SHA256 哈希键名 + HMAC 签名布尔值防篡改
- **图片本地化**：拍照/选图后复制到应用文档目录，防止缓存清除

### 22. 数据备份与恢复
- **JSON 备份**：导出全部思考卡为 JSON 文件到 Download/zoosy/backup/
- **数据恢复**：从 JSON 文件导入，支持 SHA256 去重，通过原生文件选择器
- **Markdown 导出**：导出为格式化 Markdown 文件到 Download/zoosy/download/

### 23. 标签管理
- **自定义标签**：添加/删除个人标签（默认：工作、生活、成长、反思、思考、健康）
- **标签筛选**：点击标签查看所有相关思考卡
- **标签统计**：统计页展示各标签记录数量和占比

## 十一、技术架构特点

| 特性 | 实现方式 |
|------|---------|
| 状态管理 | StatefulWidget + 回调函数（无第三方状态管理库） |
| 本地存储 | SharedPreferences（JSON 序列化） |
| 安全存储 | SecurePrefs（SHA256 键混淆 + HMAC 布尔签名） |
| 通知 | flutter_local_notifications（本地定时） |
| 桌面小组件 | home_widget + MethodChannel 双通道 |
| 语音识别 | speech_to_text |
| AI 接入 | OpenAI 兼容 API + Anthropic API |
| 邮件发送 | mailer 包（QQ 邮箱 SMTP） |
| 图片选择 | image_picker |
| 图片分享 | RepaintBoundary → PNG → share_plus |
| 国际化 | 自研 TranslationService（非 Flutter intl） |
| 主题切换 | 动态 ThemeData + SharedPreferences 持久化 |
| 云同步 | 接口已预留（CloudService 为 Stub） |
